# 🎵 Spotify Clone

A high-fidelity, interactive music streaming web application built using pure client-side web technologies. This project replicates the core user experience, layout, and event-driven audio playback architecture of modern streaming platforms.


---

## 🛠️ Tech Stack & Architecture

* **Frontend:** Semantic HTML5, CSS3 (Custom Properties, Flexbox, Grid)
* **Engine:** Vanilla JavaScript (ES6+, Event-driven Architecture)
* **Audio Engine:** HTML5 Audio API

---
